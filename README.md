# RPG Harness

Локальный однопользовательский харнес, в котором нейросеть ведёт текстовую RPG как гейм-мастер. Модель решает, что происходит, а код считает кости, здоровье, баланс встреч, опыт, добычу и цены.

## Требования и запуск

- .NET 10 SDK;
- OpenAI-совместимый API;
- Windows рекомендуется для системного диалога выбора папки, остальная часть приложения кроссплатформенная.

```powershell
dotnet restore
dotnet run --launch-profile http
```

После запуска откройте <http://localhost:5193>, выберите язык и заполните настройки подключения. Локальная конфигурация сохраняется в `.harness/settings.json` и намеренно исключена из Git.

## Безопасность

RPG Harness хранит API-ключ в локальном файле и работает с выбранной пользователем директорией. По умолчанию приложение отклоняет запросы не с loopback-адреса.

Не публикуйте приложение напрямую в интернете. Для осознанного сетевого развёртывания можно установить `Harness:AllowRemoteAccess=true`, но перед этим необходимо поставить внешний слой аутентификации и TLS. Локальный reverse proxy считается локальным клиентом и поэтому также обязан требовать аутентификацию.

Никогда не добавляйте в Git:

- `.harness/` — настройки и API-ключи;
- рабочую директорию с `chats/`, `rpg/` и `campaigns/`;
- `tools/.harness/` — временные профили браузера.

# Графика: портреты, иконки, предметы

Как устроены картинки харнеса, как Мастер их выбирает и как добавить новые.

## Как Мастер выбирает картинку

| Что | Каталог | Как выбирается |
|---|---|---|
| Портреты врагов, спутников, героя | `wwwroot/sprites/portraits.json` (собирает `tools/sprites/build_portraits.py`) | Модель передаёт смысловой id (`wolf`, `lich`, `human-female-mage`). Если id не похож на имя существа («Волк» с портретом гоблина) или не указан — `PortraitCatalog` подбирает облик по основам слов в имени. Старые адреса `classic:3`, `monster:3` продолжают работать. |
| Иконки навыков | `Services/SkillIcons.cs` (лист `combat-icons-loot.png`, 8×8) | Явный id → совпадение слов в названии и описании навыка («Ледяная стрела» → `frost`) → иконка категории. |
| Иконки предметов | `wwwroot/sprites/items.json` + `rpg-items.png` (собирает `tools/sprites/build_items.py`) | id из каталога или угадывание по названию. Зелья в справке модели подписаны по функции (`potion_red — малое зелье лечения`). |

## Добавить новый лист портретов

1. Сгенерируйте квадратный лист **4×4** (любой размер, например 1254×1254; позиции в CSS заданы в процентах)
   и положите в `wwwroot/sprites/`, например `enemy-portraits-beasts2.png`.
2. В `tools/sprites/build_portraits.py` добавьте лист в `SHEETS` и по строке `add(...)` на каждую клетку:
   ```python
   SHEETS["beasts2"] = {"file": "enemy-portraits-beasts2.png", "cols": 4, "rows": 4}
   add("bear", "beasts2", 0, "Бурый медведь", "beast", "ordinary", "медвед медведиц гризли bear")
   ```
   Основы слов — начала слов без окончаний («медвед» ловит «медведь», «медведица», «медвежий»).
   Для лиц спутников — `person=True` и пол `"m"`/`"f"`.
3. `python tools/sprites/build_portraits.py`, затем пересоберите проект (`dotnet build`) — новые PNG из
   `wwwroot` попадают в манифест статических файлов только при сборке.

Порядок и клетки уже существующих записей не меняйте — id сохранены в кампаниях. Новое — только дописывать.

Цветовые вариации существующих портретов добавляются строкой в `VARIANTS` (`tools/sprites/build_variants.py`)
и записью в `V` в `build_portraits.py`: диапазон оттенков, которые перекрашиваем, сдвиг тона, насыщенность, яркость.

## Промпты для генерации в стиле проекта

Исходные листы нарисованы генератором изображений в одной манере: детальный «живописный» пиксель-арт
16-бит, мрачное фэнтези, драматический контровой свет. Чтобы новые листы не выбивались, держите общий
каркас промпта и меняйте только список существ. Генерируйте сразу сеткой 4×4 — так манера и освещение
у 16 портретов получаются согласованными.

### Враги

```
A 4x4 grid sprite sheet of 16 square dark fantasy enemy portraits, detailed 16-bit pixel art with painterly
shading, bust or upper-body shots, dramatic rim lighting, glowing eyes, muted deep crimson, charcoal and bronze
palette, gothic castle spires and ruins silhouetted in a dark red-black background, each portrait in its own
square cell separated by a thin dark frame, consistent lighting and scale, no text, no watermark.
Portraits, left to right, top to bottom: 1) ..., 2) ..., ... 16) ...
```

Чего не хватает (кандидаты на следующие листы):

* **Звери и чудовища:** бурый медведь, гигантская крыса, стая нетопырей, гарпия, мантикора, минотавр,
  грифон, виверна, гидра (живая), кракен, болотный крокодил, гиена, гигантский червь, химера, василиск,
  кентавр-разбойник.
* **Гуманоиды:** кобольд, хобгоблин-воин, гнолл, орк-воин, лучник-разбойник, арбалетчик-наёмник,
  алебардщик городской стражи, некромант-человек, жрица тьмы, эльф-лучник, дуэргар-воин, болотная ведьма,
  пиратский капитан, тёмный паладин, гладиатор, работорговец.
* **Нежить, демоны, фейри:** гуль, скелет-лучник, призрачный рыцарь, зомби-великан, бес, суккуб,
  горгулья, треант, дриада, фея-проказница, кошмарный конь, баньши-королева, некро-дракон, вестник бездны,
  огненный элементаль (гуманоидный), водяной элементаль.

### Спутники и NPC

```
A 4x4 grid sprite sheet of 16 square fantasy adventurer portraits, detailed 16-bit pixel art with painterly
shading, head-and-shoulders, three-quarter view, warm candle-like light, dark charcoal background with a faint
heraldic emblem in the top-left corner of each cell, each portrait in its own square cell separated by a thin
dark frame, noble and characterful faces, no text.
Portraits: 1) female dwarf blacksmith with braided red hair, 2) female orc warrior with tusks, ...
```

Не хватает комбинаций раса × пол (сейчас облик другого пола не подставляется, берётся человек):
дварфийка, орчиха, гномы обоих полов, тифлинг-мужчина, драконорождённая, полурослица, кошколюд-мужчина,
гоблинша, эльфийка-маг, эльф-воин, людоящер-союзник, птицелюд; а также NPC-архетипы: трактирщик, торговка,
старуха-травница, городской стражник, аристократка, юный паж, монах, бард.

### Иконки навыков и материалов (лист 8×8)

```
An 8x8 grid of 64 square fantasy RPG skill and loot icons, glossy painterly pixel art, vivid glowing colors
on a dark rounded-square tile with a thin bronze-grey frame, centered subject, strong silhouette, no text.
Icons: 1) bow shot with motion streak, 2) volley of arrows, 3) taunt shout, ...
```

Кандидаты: выстрел из лука, залп, провокация, призыв зверя, телепорт, некро-призыв, вампиризм, кислотный
плевок, землетрясение, метка охотника, кровотечение-клинок, песнь барда, дымовая бомба, ловушка, стойка
щита, воскрешение-феникс; материалы — перья, эктоплазма, адская сера, глаз чудовища, рог единорога.
Иконки навыков описаны в `SkillIcons.All` (индекс = клетка листа, основы слов для подбора). Сейчас класс
работает с одним листом `combat-icons-loot.png`; для второго листа в запись `Icon` нужно добавить имя листа
и учесть его в `SkillIcons.Style`.

## Киберпанк: графика и живописные портреты

Предметы, навыки и меню сеттинга «Киберпанк» рисуются процедурно (Pillow) в одной манере — пиксель-арт с тёмным
контуром, затенением кромок и неоновыми акцентами. Общая кисть — `tools/sprites/pixelkit.py` (многоугольники в
локальных координатах «вдоль/поперёк» предмета, поэтому одно оружие можно положить горизонтально или по диагонали,
как мечи DCSS). Портреты в приложении используют более детальные живописные листы; их полноразмерные мастера лежат
в `tools/sprites/painterly/`.

| Что | Скрипт | Результат |
|---|---|---|
| 143 предмета (32×32) | `build_cyber_items.py [--preview <png>]` | `cyber-items.png`, `cyber-items.json` (с уроном, бронёй, ценой, категорией торговли), `css/pixel-cyber.css` |
| 54 процедурных портрета (запасной вариант) | `build_cyber_portraits.py [street|machines|persons|hero]` | `cyber-enemies-street.png`, `cyber-enemies-machines.png`, `cyber-persons.png`, `cyber-hero-avatars.png` |
| 54 живописных портрета (штатный вариант) | `install_painterly_portraits.py` | Те же четыре листа из мастеров `tools/sprites/painterly/` |
| Иконки навыков (8×8) и меню досье (3×3) | `build_cyber_skills.py` | `cyber-skill-icons.png`, `cyber-book-menu.png` |

После изменения состава или порядка портретов запустите `build_portraits.py` (киберпанковые записи там с
`genre: cyberpunk`), затем `dotnet build`. `build_cyber_portraits.py` перезаписывает живописные листы процедурными;
после него верните штатную графику командой `python tools/sprites/install_painterly_portraits.py`.

* **Портреты** собираются из частей: фон (ночной город, неоновая вывеска, дождь, тема из `THEMES`), торс
  (`jacket`, `armor`, `suit`, `hoodie`, `vest`, `coat`, `tank`, `robe`), лицо по полу и тону кожи, причёска
  (`buzz`, `mohawk`, `bob`, `long`, `pony`, `undercut`, `slick`, `spiky`, `dreads`, `hood`, `cap`, `bald`),
  моды (`visor`, `goggles`, `cybereye`, `plate`, `jaw`, `mask`, `tattoo`, `dots`, `cables`, `antenna`, `scar`,
  `headset`, `chain`, `shades`, `katana`, `helmet`, `robot_head`). Машины, программы и мутанты — отдельные
  рисовалки (`drone_sec`, `mech`, `cyberdog`, `ai_ghost`, `ice_daemon`, `ai_core`…). Новый облик — строка в списке
  листа и запись в `build_portraits.py`; порядок клеток — только дописывать.
* **Иконки предметов** — функции-рисовалки по типам (`pistol`, `smg`, `rifle`, `blade`, `jacket`, `exo`,
  `helmet`, `chip_implant`, `injector`, `grenade`…). Новая вещь — строка в `CATALOG` (в конец).
* Лист навыков повторяет порядок 64 клеток фэнтезийного листа: огонь → термический урон, молния → ЭМИ,
  свет → лазер, книги → чипы программ. Смысл клеток в киберпанке — словарь `Cyber` в `SkillIcons.cs`.

### Промпты для живописной замены листов киберпанка

Если захочется живописной манеры, сгенерируйте лист тем же размером сетки и с тем же порядком клеток
и положите поверх файла из таблицы — код менять не нужно.

```
A 4x4 grid sprite sheet of 16 square cyberpunk character portraits, detailed 16-bit pixel art with painterly
shading, bust shots, neon rim lighting (cyan from the left, magenta from the right), rainy megacity skyline
with lit windows and neon signs in a dark background, chrome implants and glowing visors, each portrait in its
own square cell separated by a thin dark frame, consistent lighting and scale, no text, no watermark.
Portraits, left to right, top to bottom: 1) ..., 16) ...
```

Порядок клеток — как в `build_cyber_portraits.py`:

* **street**: ганкер с тату; бандитка с розовым каре; панк с зелёным ирокезом; громила с железной челюстью;
  корпоративный охранник в шлеме с синим визором; корпоративный штурмовик с красным визором; полицейский в кепи
  с гарнитурой; нетраннерша в капюшоне с очками и кабелями; киберпсих с хромированной половиной лица;
  киберниндзя в маске с катаной; наёмник-ветеран с кибер-глазом и бородой; снайперша с кибер-глазом;
  техножрец в капюшоне с металлической челюстью; рейдер Пустошей в противогазе и очках; фиксер-босс в
  тёмных очках и золотой цепи; директор корпорации в белом костюме со светящимися глазами.
* **machines**: охранный дрон с красным глазом; боевой квадрокоптер; автоматическая турель; боевой робот с
  красными глазами; андроид с белым лицом и швами; шагающий мех; киберпёс; крыса-мутант; мутант с наростами;
  сетевой призрак из каркасных линий; демон-защитник ICE (геометрический глаз); паук-робот; киборг-титан;
  военный мех с пушками; ядро сверхразума (огромный красный глаз в кольцах); андроид-убийца в чёрном.
* **persons**: соло с кибер-глазом (м); соло с тату (ж); нетраннерша с визором; нетраннер в очках с дредами;
  техник в очках-гогглах; техничка с гарнитурой; медтех (ж) в белом; медтех (м) с визором; кочевник с бородой;
  кочевница; фиксер в бордовом костюме; корпоратка в тёмно-синем; рокер-киборг с хромом на лице;
  барменша с красными волосами; коп в кепи; панкушка с ирокезом.
* **hero** (3×2): соло, раннер в капюшоне, нетраннер с визором — мужчины; соло, раннерша, нетраннерша — женщины.

## Современность: графика, нарисованная кодом

Сеттинг «Современность» рисуется теми же кистями, что и киберпанк, но в приземлённой палитре: воронёный металл,
чёрный полимер, дерево, олива, хаки — без неона.

| Что | Скрипт | Результат |
|---|---|---|
| 119 предметов (32×32) | `build_modern_items.py [--preview <png>]` | `modern-items.png`, `modern-items.json`, `css/pixel-modern.css` |
| 54 процедурных портрета (запасной вариант) | `build_modern_portraits.py [street|threats|persons|hero]` | `modern-enemies-street.png`, `modern-enemies-threats.png`, `modern-persons.png`, `modern-hero-avatars.png` |
| 54 живописных портрета (штатный вариант) | `install_painterly_portraits.py` | Четыре листа из мастеров `tools/sprites/painterly/modern-*-master.png` |
| 16 сверхъестественных врагов (живописный лист 4×4) | внешний генератор, порядок закреплён в `build_portraits.py` (`MN`) | `modern-enemies-supernatural.png` |
| Иконки навыков (8×8) и меню «Личного дела» (3×3) | `build_modern_skills.py` | `modern-skill-icons.png`, `modern-book-menu.png` |

Процедурные портреты используют `person()` из `build_cyber_portraits.py` с подменённым фоном (`backdrop`): вечерний город
с жёлтыми окнами и натриевыми фонарями, мигалки для полиции, ельник для военных и зверей. Одежда современности:
`tshirt`, `tracksuit`, `police`, `camo`, `scrubs`, `plate`; моды: `balaclava`, `beanie`, `glasses`, `earpiece`,
`mil_helmet`, `bandana`, `cigarette`, `bruise`, `headphones`. Звери и техника — отдельные рисовалки
(`dog`, `wolf`, `bear`, `boar`, `suv`, `technical`, `police_car`, `helicopter`, `quad`).

Все четыре листа по умолчанию берутся из живописных мастеров: герои 3×2, остальные — 4×4. В выборе героя
доступны 39 человеческих портретов из листов hero, persons, street и threats; звери, техника и закрытые масками
противники остаются только портретами встреч. Порядок клеток и id не изменены, поэтому существующие сохранения
продолжают указывать на тех же персонажей. После `build_modern_portraits.py`, который создаёт запасные
процедурные листы, верните штатную графику командой `python tools/sprites/install_painterly_portraits.py`.
Отдельный `modern-enemies-supernatural.png` этот скрипт не перезаписывает: в нём призраки, вампиры, оборотень,
культист, ревенант, банши, демоны, оживший манекен, горгулья, аберрации, элементаль и небожитель.

Промпт для живописной замены — как у киберпанка, но фон «вечерний город, натриевые фонари, мокрый асфальт»
и без неона; порядок клеток — как в `build_modern_portraits.py`.
